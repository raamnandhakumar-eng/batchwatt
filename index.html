BatchWatt AI · automation-first demo

Factory planning with monthly-peak-aware demand charges.

BatchWatt automatically collects WhatsApp orders, stock sheets, electricity bills, LPG receipts, and meter logs. It creates a dispatch-first plan, then splits the energy receipt into usage savings this run and demand-charge savings only when today would set a new billing-month peak.

Automation run

Daily input: none typed from scratch. Orders arrive through WhatsApp. Stock comes from the existing sheet. Bills and LPG receipts are parsed when they arrive. Manual work only happens when confidence is low.
